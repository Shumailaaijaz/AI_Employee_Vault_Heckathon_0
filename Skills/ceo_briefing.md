# Skill: CEO Briefing Generation

## Purpose
Generate the Monday Morning CEO Briefing — a weekly executive summary of business activity, financials, bottlenecks, and proactive suggestions.

## When to Use
- Scheduled: Every Monday at 7:00 AM (via Orchestrator scheduler)
- On demand: When asked to "generate a briefing" or "summarize the week"

## Instructions

1. **Gather data** from these sources:

| Source | What to Extract |
|--------|----------------|
| /Done/ (last 7 days) | Completed tasks, count, categories |
| /Logs/ (last 7 days) | All actions taken, error counts |
| /Accounting/Current_Month.md | Revenue, expenses, transactions |
| /Needs_Action/ | Outstanding items (backlog) |
| /Plans/ | In-progress work |
| Business_Goals.md | Targets and KPIs to compare against |

2. **Analyze** the data:
   - Calculate total revenue for the week
   - Identify tasks that took longer than expected (bottlenecks)
   - Spot recurring expenses or suspicious transactions
   - Check progress against Business_Goals.md targets
   - Count actions by category (emails, posts, payments, etc.)

3. **Generate suggestions** — be proactive:
   - Flag unused subscriptions (no activity in 30+ days)
   - Suggest follow-ups on stale leads (no reply in 48+ hours)
   - Highlight upcoming deadlines from /Plans/ and /Active_Project/
   - Recommend cost optimizations

4. **Write the briefing** to:
   ```
   /Briefings/YYYY-MM-DD_Monday_Briefing.md
   ```

5. **Update Dashboard.md** with a link to the new briefing.

## Output Format
```markdown
---
generated: <timestamp>
period: <start_date> to <end_date>
type: ceo_briefing
---

# Monday Morning CEO Briefing

## Executive Summary
<2-3 sentence overview of the week>

## Revenue & Financials
| Metric | This Week | MTD | Target |
|--------|-----------|-----|--------|
| Revenue | $X | $Y | $Z |
| Expenses | $X | $Y | - |
| Net | $X | $Y | - |

## Completed Tasks (X total)
- [x] <task 1>
- [x] <task 2>

## Bottlenecks
| Task | Expected | Actual | Delay |
|------|----------|--------|-------|
| <task> | X days | Y days | +Z days |

## Outstanding Items (backlog: X)
- [ ] <item 1> (age: X days)
- [ ] <item 2> (age: X days)

## Proactive Suggestions
1. **<suggestion title>**: <detail + recommended action>
2. **<suggestion title>**: <detail + recommended action>

## Upcoming Deadlines
| Deadline | Project | Days Left |
|----------|---------|-----------|
| <date> | <project> | X days |

---
*Generated by AI Employee*
```

## Rules
- Always compare against Business_Goals.md targets
- Never fabricate financial data — use only what's in /Accounting/
- If data is missing, note it explicitly ("No financial data available for this period")
- Keep the briefing under 500 words
- Flag any anomaly (unusual transaction, spike in errors, missed deadlines)
